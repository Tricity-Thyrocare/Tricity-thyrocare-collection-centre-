# Tricity Thyrocare Collection Centre Website

Premium responsive diagnostic website with:
- Bright multicolour healthcare home page
- Health package cards
- Online booking modal
- Date and time-slot selection
- Home collection / centre visit selection
- WhatsApp booking handoff to 8178009011
- Mobile responsive design

## Files
- index.html
- style.css
- script.js

## Deploy
Upload all 3 files to your hosting/GitHub Pages root and open index.html.
